# 🎙️ نواکست — تبدیل هوشمند صوت به زیرنویس SRT

> Flask + OpenAI Whisper — آپلود فایل صوتی/تصویری، تشخیص گفتار و دانلود زیرنویس `.srt`
> رابط کاربری فارسی و راست‌چین با فونت وزیرمتن

## ✨ ویژگی‌ها

- 🎧 آپلود فایل صوتی یا ویدیویی تا **500 مگابایت** با درگ‌دراپ + پیش‌نمایش پخش صوت/ویدیو
- 🌍 زبان: **تشخیص خودکار / فارسی / انگلیسی**
- 🧠 انتخاب مدل هنگام تبدیل: **Medium** (پیش‌فرض)، **High / Large v3** یا **Persian** (بهترین خروجی فارسی)
- ⬇️ دانلود مدل‌های **High** و **Persian** مستقیماً از داخل برنامه با نوار پیشرفت، ادامه دانلود ناقص (**resume**) و بررسی **SHA256**
- ⚡ لود مدل در **پس‌زمینه** — سرور بلافاصله بالا می‌آید، صفحه وضعیت مدل را نشان می‌دهد
- 🎮 تشخیص خودکار **GPU (CUDA)** و fallback به CPU
- ✂️ حالت خروجی **کلمه‌به‌کلمه** با زمان‌بندی اصلی هر کلمه (مناسب ادیت) + خروجی جمله‌ای معمولی
- 📝 تولید **SRT استاندارد** + پیش‌نمایش متن + نمایش زبان شناسایی‌شده و تعداد بخش‌ها/کلمات
- ⬇️ دانلود فایل `.srt` (محافظت‌شده در برابر Path Traversal)
- 🧹 پاک‌سازی خودکار فایل‌های صوتی/ویدیویی موقت قدیمی‌تر از ۲۴ ساعت (خروجی‌های `.srt` حفظ می‌شوند)
- 🖥️ لانچر ویندوزی (`run.bat`) با باز شدن خودکار مرورگر و نمایش لاگ زنده
- 💜 UI تیره، مدرن و ریسپانسیو (Vazirmatn، RTL)

فرمت‌های صوتی: `mp3, wav, m4a, ogg, oga, flac, aac, wma, opus, aif, aiff`

فرمت‌های ویدیویی: `mp4, m4v, mkv, mov, webm, avi, mpg, mpeg, m2ts, ts, 3gp, flv`

## ✅ پیش‌نیازها

- Windows 10/11 (64-bit)
- Python **3.11**
- کارت NVIDIA + درایور CUDA (اختیاری — برای سرعت بیشتر؛ بدون آن روی CPU کار می‌کند)
- اینترنت برای دانلود مدل پیش‌فرض (~1.5 گیگ)؛ مدل‌های High و Persian اختیاری‌اند (~3 گیگ هر کدام)

## 🚀 اجرا (پیشنهادی — ویندوز)

```bat
# 1) یک‌بار: ساخت محیط مجازی پایتون 3.11
py -3.11 -m venv venv311
venv311\Scripts\activate
pip install -r requirements.txt

# 2) هر بار: دابل‌کلیک روی run.bat
run.bat
```

مرورگر خودکار روی http://127.0.0.1:8000 باز می‌شود.
(اولین اجرا ۱–۲ دقیقه طول می‌کشد چون مدل دانلود/لود می‌شود — پنجره را نبندید.)

## 🖱️ نحوه استفاده

1. فایل صوتی یا ویدیویی را درگ کنید یا کلیک کنید و انتخاب کنید
2. زبان را انتخاب کنید (تشخیص خودکار / فارسی / English)
3. مدل را انتخاب کنید:
   - **Medium**: سریع‌تر و پیش‌فرض
   - **High (Large v3)**: دقیق‌تر برای محتوای عمومی؛ اگر نصب نباشد از همان صفحه دکمه **دانلود High** را بزنید
   - **Persian**: مدل فاین‌تیون فارسی با نشانه‌گذاری و خروجی تمیز؛ برای زیرنویس فارسی بهترین گزینه است. اگر نصب نباشد دکمه **دانلود Persian** را بزنید
4. حالت خروجی را انتخاب کنید:
   - **جمله‌ای**: SRT استاندارد و سریع‌تر برای پخش
   - **کلمه به کلمه**: هر کلمه با زمان‌بندی اصلی Whisper جدا می‌شود (برای ادیت)
5. دکمه **تبدیل به زیرنویس** را بزنید
6. پیش‌نمایش متن را ببینید و فایل `.srt` را دانلود کنید
   (در حالت کلمه‌به‌کلمه، نسخه جمله‌ای هم برای دانلود آماده است)

## 🇮🇷 مدل فارسی

- مدل: [`givia/whisper-large-v3-turbo-persian`](https://huggingface.co/givia/whisper-large-v3-turbo-persian) — فاین‌تیون `whisper-large-v3-turbo` روی داده‌های فارسی
- خروجی: فارسی محاوره‌ای با **نشانه‌گذاری** (ویرگول، نقطه، علامت سؤال) و کیفیت تمیزتر از Medium/High برای گفتار فارسی
- مجوز مدل: **CC-BY-4.0** — اعتبار مدل متعلق به سازندهٔ آن است
- اجرا با **Hugging Face Transformers** در حالت fp16 روی GPU (حدود ۱٫۵ گیگابایت VRAM) و همیشه با زبان `fa`
- برای دانلود، تب **Persian** را انتخاب کنید و دکمهٔ **دانلود Persian** را بزنید (حدود ۳ گیگابایت، فقط یک‌بار)

## 🔌 API

| متد | مسیر | توضیح |
|---|---|---|
| `GET` | `/` | صفحه اصلی |
| `GET` | `/health` | وضعیت سرور و مدل (`model_loaded`, `active_model`, `model_loading`, `device`) |
| `GET` | `/models` | فهرست مدل‌ها، نصب/دانلود/درصد پیشرفت و مدل فعال |
| `POST` | `/models/download` | شروع دانلود یک مدل در پس‌زمینه — بدنه JSON: `{"model_id":"large-v3"}` یا `{"model_id":"persian"}` |
| `POST` | `/upload` | آپلود فایل (`file` + `language`: `auto`/`fa`/`en` + `output_mode`: `segment`/`word` + `model`: `medium`/`large-v3`/`persian`) — خروجی JSON شامل `srt_filename`، `mode`، `model`، `words_count` و `preview` |
| `GET` | `/download/<filename>` | دانلود فایل SRT (پارامتر اختیاری `name` برای نام نمایشی) |

مثال:

```bash
curl -F "file=@voice.mp3" -F "language=auto" -F "output_mode=segment" -F "model=medium" http://127.0.0.1:8000/upload

# زیرنویس کلمه‌به‌کلمه با مدل High (باید قبلاً دانلود شده باشد)
curl -F "file=@clip.mp4" -F "language=auto" -F "output_mode=word" -F "model=large-v3" http://127.0.0.1:8000/upload

# زیرنویس فارسی با مدل Persian (باید قبلاً دانلود شده باشد)
curl -F "file=@voice.mp3" -F "language=fa" -F "output_mode=segment" -F "model=persian" http://127.0.0.1:8000/upload
```

## ⚙️ تنظیمات مهم

- مدل‌های قابل انتخاب در `app.py` داخل `MODEL_SPECS` تعریف می‌شوند (`medium`، `large-v3` و `persian`)
- مدل‌های High و Persian از داخل UI دانلود می‌شوند و در `~/.cache/whisper` ذخیره می‌شوند
- مدل Persian همان `givia/whisper-large-v3-turbo-persian` است که با `transformers` اجرا می‌شود (نسخهٔ مدل پین شده تا حجم/فایل‌ها ثابت بمانند)
- هر بار فقط یک مدل در حافظه/GPU نگه داشته می‌شود؛ سوییچ مدل ممکن است ۱–۲ دقیقه طول بکشد
- مدل Persian در حالت fp16 روی GPU حدود ۱٫۵ گیگابایت VRAM می‌گیرد؛ نسخهٔ کامل فایل‌ها حدود ۳ گیگابایت است
- پورت: `8000` | حد آپلود: `500MB` (`MAX_CONTENT_LENGTH`)
- کش مدل: `~/.cache/whisper`
